# Beer Images

This directory contains placeholder SVG images for each beer in the BeerRanker application.

## Replacing Placeholder Images

The current SVG files are placeholders. To use actual beer product images:

1. Replace each `.svg` file in the `beers/` directory with a real product image
2. Keep the same filename (e.g., `bud-light.svg` → `bud-light.jpg` or `bud-light.png`)
3. Update the file extensions in `/index.html` if changing from SVG to JPG/PNG
4. Recommended image dimensions: 400x400px (square) for best display
5. Supported formats: SVG, PNG, JPG, WebP

## Where to Find Beer Images

- Official brand websites (check licensing)
- Free stock photo sites (Unsplash, Pexels, Pixabay)
- Product databases (ensure commercial use is allowed)
- Take your own photos

## Image Guidelines

- Use consistent image dimensions across all beers
- Optimize file sizes (compress images to reduce load times)
- Ensure images are clear and recognizable
- Respect copyright and licensing terms
